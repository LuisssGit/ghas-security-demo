**Política de Seguridad
Versiones compatibles

Este proyecto es un proyecto de demostración de seguridad. Actualmente, la versión disponible en la rama main es la versión compatible.

Versión	Compatible
main	:white_check_mark:
Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este proyecto, puedes reportarla a través de GitHub.

Incluye, por favor:

Una descripción de la vulnerabilidad.
Los pasos necesarios para reproducirla.
El posible impacto de la vulnerabilidad.
Capturas de pantalla, registros o pruebas de concepto relevantes.

Por favor, no hagas pública la vulnerabilidad antes de que haya sido revisada.

Respuesta

Los reportes de seguridad serán revisados lo antes posible. Si se confirma la vulnerabilidad, se tomarán las medidas necesarias para solucionarla.

Gracias por ayudar a mejorar la seguridad de este proyecto.
